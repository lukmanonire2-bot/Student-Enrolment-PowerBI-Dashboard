# Student-Enrolment-PowerBI-Dashboard
Student Enrolment & Training Programme Dashboard

Project Overview

This project involves developing an interactive Power BI dashboard to analyse student enrolment and training programme data. The dashboard provides insights into student participation, course enrolment and programme distribution.

Objectives

* Analyse student enrolment patterns.
* Understand enrolment distribution across courses.
* Present key information through interactive visualisations.
* Support better understanding of training programme performance.

Tools Used

* Microsoft Power BI
* Data Cleaning
* Data Analysis
* Data Visualisation

Dashboard Preview

Key Features

* Student enrolment analysis.
* Enrolments by course.
* Interactive dashboard visuals.
* Summary of important enrolment information.

Project Purpose

This project demonstrates the use of data visualisation and business intelligence techniques to transform student enrolment data into meaningful insights.
